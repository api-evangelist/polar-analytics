# Polar Analytics

> Polar is an all-in-one data analytics and AI platform purpose-built for Shopify-based ecommerce and DTC brands. It consolidates data from 45+ sources into a personal Snowflake warehouse, ships 400+ pre-built ecommerce metrics with a semantic layer, and exposes them to agents through the hosted Polar Headless MCP server. This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer surface (method: generated).

## APIs

- [Polar Headless MCP (tools-as-API)](https://intercom.help/polar-app/en/articles/12960325-using-mcp-tools-as-an-api): Hosted MCP server at https://api.polaranalytics.com/mcp; POST /mcp/tool/<tool_name>; Bearer API key auth.
